# Examples

[standalone/](standalone/) is a complete minimal declared input set for one portable three-server cluster. It is the primary [installation starting point](../agents/installation.md), separate from the larger optional integrated composition in [data/](../data/README.md).

[optional-aci-transit/](optional-aci-transit/) contains separately selected fabric/edge fragments; it is not a prerequisite for portable installation. Versioned schemas under [schemas/](../schemas/README.md) describe their own document contracts; a schema is not another deployment input set.
